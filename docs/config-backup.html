Manage which ADO projects are included in daily config backups. View backup status per project — last backup date, wiki repos discovered, and component counts.
What Gets Backed Up
✅ Included in backup
  • 🔄 Build pipeline definitions (classic + YAML settings)
  • 🔄 Release pipeline definitions
  • 🔐 Variable groups (secret values masked by ADO)
  • 🔗 Service connections (credentials excluded by ADO)
  • 🌏 Environments
  • 📊 Dashboards
  • 📖 Wiki repos (names + content mirrored to GitHub)
  • 🧰 Agent pools (org-level)
⚠ Not included / separate handling
  • 🔓 Secret variable values (ADO never exposes these via API)
  • 🔓 Service connection credentials (same — by design)
  • 📋 Work items / boards (use ADO Migration Tools for these)
  • 🧩 Test plans & cases (export manually or via migration tools)
  • 📦 Artifact packages (handled separately per feed)
