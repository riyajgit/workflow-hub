Disaster Recovery — WorkflowHub
This portal manages the automated DR mirroring of your Azure DevOps repositories to GitHub. Repositories are mirrored on a nightly schedule (18:00 UTC) using the dr-mirror.yml workflow. In the event of an ADO outage or data loss, mirrored repos can be restored back to ADO via the Restore Drill workflow — fully isolated, non-destructive, and auditable.
ADO → GitHub mirror active 🔒 Non-destructive restore 🕐 Nightly at 18:00 UTC 📋 GitHub Actions powered
DR Architecture & Workflow

The DR pipeline consists of four automated GitHub Actions workflows that work together to keep your ADO repos backed up and restorable at all times.

📄 dr-list-repos.yml — Discovers ADO repos
→
✅ dr-select-repos.yml — Writes repos.json
→
🔄 dr-mirror.yml — Nightly ADO → GitHub
→
🔁 dr-restore-drill.yml — Mock restore to ADO
Backup guarantees
• Full bare-clone mirror (all branches & tags)
• Isolated GitHub repos per ADO repo
• Commit parity verified on each run
Restore safety
• Restores to a separate ADO project/org
• Refuses to overwrite existing repos
• Suffix-based naming prevents collision
